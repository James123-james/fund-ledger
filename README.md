# 基金台账

个人自用的基金操作台账与配置分析工具。记录建仓、加仓、减仓、清仓、定投，自动算成本与盈亏，对照投资模板看配置偏离，并能把任意区间的记录导出成 AI 读得懂的文件。

零第三方依赖，只用 Python 标准库。数据存在本地一个 SQLite 文件里。

---

## 快速开始

**Windows**：双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:8787`。

**命令行**：

```bash
python server.py                 # 默认 127.0.0.1:8787
python server.py --port 9000     # 换端口
python server.py --no-browser    # 不自动开浏览器
```

需要 Python 3.10 或更高版本，无需 `pip install` 任何东西。

### 先看看它长什么样

项目自带一份演示数据，不影响你自己的账本：

```bash
python server.py --data demo
```

演示库里有三只基金、30 多笔流水，能直接看到完整的持仓、曲线和配置分析。

### 从手写记录批量导入

如果你已经有一份文字版的理财记录（比如记在备忘录里），可以把它整理成规则再批量导入，不必一条条手录。

先把示例规则复制成自己的：

```bash
cp tools/plan.example.py tools/plan.py
```

然后照着改 `tools/plan.py`，再执行：

```bash
python tools/import_records.py --dry-run    # 先预演，看清楚会生成什么
python tools/import_records.py              # 确认无误后正式写入
```

> `tools/plan.py` 里是你真实的基金代码和金额，已写进 `.gitignore`，不会被提交到仓库。仓库里只有脱敏的 `plan.example.py`。

规则是声明式的，支持这些写法：

| 写法 | 含义 |
| --- | --- |
| `buy` | 按金额买入，份额与手续费按当日净值和基金费率自动算 |
| `sell` | 按金额卖出，份额按当日净值折算 |
| `close` | 清仓，份额自动取当时持仓 |
| `sip` | 定投，按 `freq` 展开成逐笔（`daily` / `mon` / `tue` … / `thu`） |

几个自动处理：

- **非交易日顺延**：写在周日的买入会记到下一个交易日，按那天的净值确认，备注里保留原始日期
- **交易日历**：定投只在真正的 A 股交易日生成，国庆、春节等假期自动跳过
- **费率**：C 类通常 0 申购费，A 类按抓到的实际费率算，金额含费
- **去重**：`--reset` 会先清空这几只基金的旧流水再导入，避免重复

### 想用手机打开

```bash
python server.py --host 0.0.0.0
```

启动后终端会打印一个局域网地址（形如 `http://192.168.1.5:8787`），手机连同一个 WiFi 就能访问。也可以双击 `start-lan.bat`。

> 这个方式只在局域网内有效，出门用不了，也不要在公共 WiFi 下开。数据始终留在你自己的电脑上。

## 它解决什么问题

| 你想知道 | 这个工具怎么回答 |
| --- | --- |
| 我这只基金到底赚了多少 | 移动加权平均法算成本单价、浮动盈亏、已实现盈亏，含手续费 |
| 我加仓那天市场是涨是跌 | 每笔操作自动带出当天的净值涨跌幅 |
| 我的配置有没有跑偏 | 对照模板算实际占比与目标占比的偏离，超阈值标红并给买卖清单 |
| 该拿新钱买什么 | 输入一笔新增资金，按「只买不卖」算出每类该买多少，并摊到具体基金 |
| 我的操作到底行不行 | 累计 vs 年化双口径 + 基准对比 + 收益归因，导出后交给 AI 复盘 |
| 亏的钱主要是哪只基金造成的 | 收益归因按百分点拆到单只，各基金相加等于组合收益率 |
| 我这样折腾比直接买指数强吗 | 同样现金流换成沪深300 模拟，排除择时差异后只比「买什么」 |
| 我录入的数据准不准 | 对账校准，跟平台数字比对，超 1% 差异标出来 |

## 功能

### 1. 操作台账

六种操作：**建仓 / 加仓 / 减仓 / 清仓 / 定投 / 分红**。

录入时只需填金额，份额和手续费按当日净值、基金实际费率自动估算（外扣法）。也可直接照抄平台确认页的份额和手续费，以你填的为准。

**成本口径**（移动加权平均，场外基金通用）：

- 金额字段 = 账户实际发生的现金额。买入是扣款总额（**已含申购费**），卖出是赎回确认总额（未扣赎回费）
- 买入：成本 += 扣款总额，份额 += 确认份额
- 卖出：按卖出当时均价释放成本，已实现盈亏 += (赎回金额 − 赎回费) − 释放成本
- 清仓：份额归零，剩余成本全部转已实现
- 现金分红：成本不变，全额计入已实现
- 红利再投：份额增加、成本不变，单价被摊薄

**批量定投**：设好起止日期、周期（每周 / 每两周 / 每月）、每期金额，一键生成整段定投记录。每个扣款日按当天净值算份额，同日已有定投记录的日期自动跳过。

### 2. 净值与涨跌幅

自动从天天基金抓取全量历史净值（通常几千条，一次请求拿完），含每日涨跌幅。点「更新净值」做增量刷新。

货币基金单独处理：净值恒为 1.0000，收益按每日万份收益逐日累计，市值 = 份额 + 累计收益，和支付宝里看到的数字一致。

### 3. 投资模板

内置五套，也可自己新建：

| 模板 | 配置 |
| --- | --- |
| 永久投资组合 | 股票 25 / 债券 25 / 黄金商品 25 / 现金 25 |
| 股债 60/40 | 股票 60 / 债券 40 |
| 全天候（简化） | 股票 30 / 债券 55 / 黄金商品 15 |
| 核心卫星 | 股票 70 / 海外 30 |
| 三基金组合 | 股票 50 / 海外 30 / 债券 20 |

每个模板可单独设偏离阈值（默认 ±5 个百分点）。系统算出各类资产的实际占比与目标占比之差，超出阈值给出再平衡建议，并摊到具体基金上。

**两种模式**：

- 默认「有买有卖」：超配的卖出、低配的买入，两边金额对得上
- 输入「新增资金」：只买不卖，把新钱优先补到低配类别；若各类都达标，剩余部分会明确告诉你没花出去

### 4. 收益质量分析

光看「亏了多少」没有意义，得知道是**时间**在拖累还是**标的**选错了。

**累计收益率 vs 年化 XIRR**

| 口径 | 算法 | 何时看它 |
| --- | --- | --- |
| 累计收益率 | 盈亏 ÷ 投入 | 看绝对结果 |
| 年化 XIRR | 按每笔现金流实际发生日折现 | 看资金效率，定投场景唯一诚实的口径 |

持有不足 90 天不给年化——18 天亏 13% 折算成年化是 −94%，数学没错但会误导。

**收益归因**

把组合盈亏拆到单只基金，给出「对该基金拉低了组合收益率多少个百分点」。各基金贡献相加恰好等于组合总收益率，可直接看出谁在拖后腿。同时按资产类别汇总，区分「配错类别」与「选错基金」。

**基准对比**

同样一笔钱、同样的买入卖出时点，如果全买沪深300 会怎样。卖出也同日等额模拟，这样差别只剩「买什么」这一项，排除了择时差异——比单看指数涨幅有意义得多。

预置沪深300、中证500、中证1000、中证红利、国债指数、创业板指、上证指数，数据取自东方财富指数日线。

**对账校准**

拿账面份额、成本单价与你从平台看到的数字比对，容差 1%。自建账本最怕静默错误——录错一位，之后所有盈亏都错，而且从界面上看不出来。差异只提示、不自动修正，并给出方向性排查建议。

### 5. 区间导出

选时间段 + 三档详略 + 三种格式：

| 档位 | 含什么 | 适合 |
| --- | --- | --- |
| 精简 | 概况、持仓、操作流水 | 快速复盘 |
| 标准 | 追加组合逐月表现、各基金月度涨跌 | 喂 AI 分析（推荐） |
| 完整 | 追加全部逐日净值与涨跌幅 | 自己算指标 |

| 格式 | 说明 |
| --- | --- |
| Markdown (.md) | 带**口径说明**和**提问建议**，AI 读完不会误解字段含义 |
| CSV (.csv) | UTF-8 BOM，Excel 双击不乱码 |
| JSON (.json) | 全量结构化，可程序处理 |

Markdown 开头有一段「数据说明」，把操作类型定义、金额口径、成本算法讲清楚；结尾有一段「分析建议提示」，列出可以直接问 AI 的五个问题。

## 数据与备份

全部数据在 `data/fund.db` 一个文件里。

- **备份**：设置页点「下载数据库备份」，或直接复制 `data/fund.db`
- **恢复**：把备份文件改名为 `fund.db` 放回 `data/`
- **重置**：关闭程序，删掉 `data/fund.db`，重新启动即恢复初始状态

### ⚠️ 不要把自己的数据提交上去

这是个自用工具，你自己的账本、导入规则、导出报告都含真实持仓和金额。`.gitignore` 已经默认排除了这几类文件：

| 文件 | 是否提交 | 说明 |
| --- | --- | --- |
| `data/fund.db` | ❌ 忽略 | 你的账本，最要紧的一个 |
| `tools/plan.py` | ❌ 忽略 | 你的导入规则，含真实基金代码与金额 |
| `fund-ledger_*.md/.csv/.json` | ❌ 忽略 | 导出的台账报告 |
| `demo/fund.db` | ✅ 提交 | 演示数据，与你的持仓无关 |

提交前建议先确认一遍：

```bash
git status --short          # 看看这次都改了什么
git check-ignore -v data/fund.db   # 确认关键文件确实被忽略
```

如果 fork 了别人的版本或者改了 `.gitignore`，务必重新核对这几条。

## 常见问题

**加了基金但没显示净值？**
可能这只基金刚成立、已清盘，或代码输错。到设置页点该基金右侧的 ↻ 重新抓取，失败会有提示。

**净值不是最新的？**
数据来自天天基金，通常每个交易日晚上更新。点右上角「更新净值」拉取。

**份额和我填的不一样？**
只有在你留空份额时系统才自动估算。如果你填了份额，系统一律以你填的为准。

**定投金额和平台扣的不一致？**
批量定投按「每期金额 ÷ (1 + 费率) ÷ 当日净值」算份额。如果平台有费率优惠或分红方式不同，以平台确认页为准，直接手改那条记录即可。

**换电脑怎么办？**
把整个文件夹拷过去，或者只拷 `data/fund.db` 到新电脑的 `data/` 目录。
