# 双轨周报 · 空白模板

这是一套**半自动版**的最低产出结构，不含任何真实持仓、金额或市场判断。  
复制 `_template/` 到 `reports/YYYY-Www/` 后开始填。

## 目录结构

```text
reports/
├── index.md                 # 所有周报的索引
├── 2026-W45/                # 按 ISO 周建目录
│   ├── data-pack.json       # 程序生成的数据包（证据底稿）
│   ├── weekly.md            # 给人读的周报
│   ├── decisions.csv        # 本周决定与复盘日期
│   └── qa.md                # 质检记录
└── 2026-W46/
    └── ...
```

模板本身在：

```text
docs/weekly-report-template/
├── README.md                # 本文件
├── index.md                 # 索引模板
└── _template/
    ├── weekly.md            # 空白周报
    ├── data-pack.json       # 空数据包结构
    ├── decisions.csv        # 决策记录表头
    └── qa.md                # 质检清单
```

## 一周流程

1. **周五收盘后**：脚本生成 `data-pack.json`（宏观、方向指标、持仓相关性、数据日期）
2. **生成周报**：AI 只读数据包，写 `weekly.md`；数字不手填
3. **人工读报告**：15–30 分钟，挑 0–3 个方向，填 `decisions.csv`
4. **质检**：`qa.md` 逐项打勾；不通过就重写，最多 2 次
5. **下周五**：更新上周方向的触发/否决状态和 `outcome`

## 硬规则

- 每周最多 **3 个方向**进入报告（价值轨、趋势轨合计）
- 没有合格方向就写「本周无合格方向」，**不操作也是正式结果**
- 不给具体基金代码、买入/卖出时点、仓位比例；只给筛选条件
- 不预测涨跌，不自动下单
- 所有数字必须有来源和日期；缺失/滞后要标出来
- 报告**不对比任何配置模板**，也不做模板偏离/再平衡建议
- 数据包和报告只存本机；不要原样发到公共 AI

## 命名

- 目录：`YYYY-Www`，例如 `2026-W46`
- 周报：`weekly.md`
- 数据：`data-pack.json`
- 决策：`decisions.csv`
- 质检：`qa.md`

## 文件说明

| 文件 | 谁生成 | 用途 |
| --- | --- | --- |
| `data-pack.json` | 脚本 | 证据底稿，供 AI 和人工核对 |
| `weekly.md` | AI + 人工 | 一页周报 |
| `decisions.csv` | 人工 | 本周决定、触发/否决条件、复盘日期 |
| `qa.md` | AI + 人工 | 质检是否通过 |
| `index.md` | 人工/脚本 | 周报索引 |
